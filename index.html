Detailed Case Studies & Architecture Reports

  • Modern Microservice Migration (Vodacom Project): Led the migration of mission-critical Deals Calculation Engine (DCE) and Online Data Query (ODQ) from legacy CORBA-based monolithic architecture to Spring Boot microservices, achieving 100% functional parity and winning the Vodacom Star Award.
  • Legacy COBOL to Java Microservices Migration: Architectural migration replacing monolithic COBOL business rules and flat-file pipelines with cloud-native Java 17 microservices, reducing transaction processing latency and hardware maintenance overhead.
  • Agentic AI CVM Microservice Transformation: Implemented an autonomous multi-agent orchestration architecture that transforms legacy Customer Value Management (CVM) logic into real-time predictive offer engines.
  • Legacy DSE-DCE (Deals Calculation Engine): Refactored and modernized 10,000+ lines of high-concurrency pricing algorithms, replacing legacy XML structures with JPA dynamic models.
  • VodaPay Business Validation (VBV): Engineered real-time financial validation microservices handling user credit eligibility, risk scores, and transaction security rules.
  • TechSonance Marketplace: Multi-tenant cloud e-commerce engine with real-time payment reconciliation and logistics webhook automation.
  • AccuNest GST Accounting & AI Suite: Tax filing and invoicing ERP featuring OCR-powered expense auditing and automated WhatsApp delivery.
  • FreightFlow Logistics OS: Comprehensive transportation management system with real-time consignment ledgers and governmental e-Way bill synchronization.
  • SyncServe Offline POS: Hybrid retail terminal operating completely offline on local SQLite and synchronizing atomically with cloud PostgreSQL instances.
  • Hisaab WhatsApp Bot: Conversational billing agent engineered with BullMQ asynchronous queue clusters, dual-persona state machines, and automated payment reconciliation.
  • Zion — Event & Ticketing Ecosystem: Enterprise ticketing ecosystem comprising a Flutter mobile application (Isar DB local caching, Socket.IO updates), modular monolith backend (zion-api), and Next.js 15 Super Admin dashboard.
  • Caven — Dubai Economy & Tourism (DET) eTicketing Engine: Government DET Sales API v1.3 integration engine with BullMQ concurrency queues, atomic seat reservation locks, and React Native mobile client.
  • OM Interior Design Studio: Luxury architecture and commercial interior studio platform built with Next.js 15, React 19, and local business Schema.org SEO engine (www.om-interior.in).
